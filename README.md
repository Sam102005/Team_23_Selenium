## 📌 About the Project

This repository contains the **Selenium Automation Assignment** completed by **Team 23**.

The project demonstrates the use of **Selenium WebDriver with Python** to automate web browser interactions, including navigating websites, interacting with web elements, handling forms, and automating different UI components.
